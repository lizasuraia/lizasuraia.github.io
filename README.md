# Liza Suraia — Architecture & Design

A standalone architectural portfolio for Liza Suraia, professionally Suraia Akter.

Open index.html directly, or run node server.cjs and visit http://localhost:4180. No installation is needed. For GitHub Pages, publish the repository root.

Edit projects.js to update projects. Personal and experience content is in index.html and resume.html. Architectural images are extracted from the supplied portfolio PDF and stored in assets/. All professional design credits and contributions are retained.

Experience is expressed as elapsed durations rather than calendar years. Contact uses the latest supplied résumé. No private street address or third-party references are published. The résumé page can be printed or saved as a PDF using its Print / Save as PDF button.

Run node scripts/build-static.cjs to generate dist/ for the existing Sites deployment. Edit root source files, not generated copies.
